# API Reference

Field-by-field reference for the custom resources that the operator owns.

* [PlatformMonitoring](platform-monitoring.md) — the single resource that describes the whole monitoring stack.
* [Prometheus Adapter](prometheus-adapter.md) — adapter rules that expose metrics to the Kubernetes metrics APIs.
* [Custom Scale Metric Rule](custom-scale-metric-rule.md) — metric rules consumed by horizontal autoscaling.
