# Grafana Stack

The Grafana operator reconciles Grafana itself and the dashboards, data sources, and folders that the monitoring stack
ships with.

* [Grafana](grafana.md): deployment, data sources, plugins, and access configuration.
* [Grafana MCP](mcp.md): in-cluster MCP server for Grafana.
* [Grafana Converter](grafana-converter.md): converts legacy `integreatly.org/v1alpha1` dashboards to Grafana Operator
  v5 resources.
